Kirana OS

Distro ringan, keren, dan minimalis berbasis Ubuntu 24.04 LTS · built by vianziro

Pasang di Ubuntu 24.04 (GNOME)

curl -fsSL https://vianziro.github.io/kirana-os/kirana-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/kirana-archive-keyring.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/kirana-archive-keyring.gpg] https://vianziro.github.io/kirana-os stable main" \
  | sudo tee /etc/apt/sources.list.d/kirana.list
sudo apt update
sudo apt install kirana-desktop
sudo reboot

Paket

  • kirana-desktop: memasang semuanya + pengaturan bawaan
  • kirana-branding: identitas distro (GRUB, splash, login, About)
  • kirana-themes: 5 tema, kursor, wallpaper dinamis, auto-tiling
  • kirana-tools: kirana, kirana-theme, kirana-keys, widget
  • kirana-vm: perbaikan khusus VirtualBox (otomatis nonaktif di PC asli)
  • fastfetch, starship: dari rilis resmi upstream

Hapus

sudo apt purge kirana-desktop kirana-branding kirana-themes kirana-tools kirana-vm
